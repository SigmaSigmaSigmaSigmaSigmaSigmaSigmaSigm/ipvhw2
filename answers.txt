Контрольні запитання

1. JavaScript можна підключити через тег script або окремий файл.
2. Оператори: +, -, *, /, ===, &&, ||, !.
3. ECMAScript — це стандарт, а JavaScript — мова, яка його реалізує.
4. for...in перебирає ключі, for...of — значення.
5. while спочатку перевіряє умову, do...while виконує тіло хоча б один раз.
6. Function declaration оголошується окремо, expression записується у змінну.
7. Контекст функції — це значення this під час виклику.
8. Об'єкт зберігає властивості. Копіювати його можна через spread або Object.assign.
9. Основні методи масивів: map, filter, find, sort, reduce.
10. Прототип дозволяє об'єктам успадковувати властивості та методи.
